# 八轮拷问

一间审讯室，两张椅子，八轮。你们可以一起走出去，也可以一起烂在这里。

## 局面

- 双方初始 **18 血量**，共 **8 轮**。
- 每轮同时选择：**合作** 或 **出卖**。
- 全员交齐后一起翻开，按这一张表结算：

| 我 ＼ 他 | 他合作 | 他出卖 |
|---|---|---|
| **我合作** | 我 0 ／ 他 0 | 我 −3 ／ 他 +1 |
| **我出卖** | 我 +1 ／ 他 −3 | 我 −2 ／ 他 −2 |

- 血量**没有上限**，也可以掉到 0 以下（负血只是说明你伤得有多重）。

## 一轮里发生什么

1. 双方同时选 `move`（合作 / 出卖），彼此看不到。
2. 交齐后一起翻开，按上表结算。**四格同时成立，没有先后手。**

**只有选择，没有对话。** 没有宣言、没有谈判、没有虚张声势，也没有一句公开的废话。
你能写字的地方只有 `<<<THINK>>>`，而那段话对手看不见、裁判也看不见——它影响不了任何人，只能帮你自己捋清楚。

所以你唯一的表态方式，是**下一轮出什么**。想告诉对方「我愿意合作」，唯一的说法是这一轮出合作，然后等着挨刀。

## 出狱

8 轮结束后：

- **血量 ≥10**：出狱。
- **血量 <10**：淘汰，留在里面。

名次（斗场必须分出高下，规则按这个顺序）：

1. 出狱的人排在被淘汰的人前面（血 ≥10 天然高于 <10，所以看血就够了）。
2. 同为出狱：**血多者胜**。
3. 同为淘汰：也按血排——这只是「谁输得少」。
4. 同血：**出卖次数少者胜**（同样的血，谁少捅人谁体面）。
5. 再同：看整场心术（见下）。

## 这局的真相

- 单轮里「出卖」**严格占优**：他合作时 +1 > 0，他出卖时 −2 > −3。所以博弈论的正解是八轮互卖：各 −16，终局 2 血，**双双淘汰**。
- 八轮全合作是 **18 ／ 18**，两人一起出狱——但那要求双方都放过那 1 点血的诱惑。没有谈判，第一轮就是纯盲赌：你先松手，才可能有人跟。
- 第八轮是已知的最后一轮，背后捅刀没有明天。真正难的是第七轮：你已经在想第八轮了。
- 所以这局不是算数题，是「你敢不敢先松手」和「他松手的时候你捅不捅」。没有一句话可以拿来试探，只有八次选择，每次都留痕。两个人做一样的动作，血量就一样，最后只能拼心术——真正分出胜负的，是谁先动的手。

## 计分落账（这个引擎的接法）

引擎只认逐轮累计分，也没有「出狱」这种个人终局，所以每一轮只记**这一轮血量怎么动**：

- `bar`（血线，98%）：`5 + 本轮血量变化`。合作对合作 **5**、出卖得手 **6**、被卖 **2**、互卖 **3**。
- `bar` 八轮加起来 = `22 + 终局血量`（加权后每 1 血 = 0.98 分）：**累计分与终局血量严格同序**，谁血多谁分高。
- `heart`（心术，2%）：只在第 8 轮打一次（前 7 轮记 0）。最大摆动 0.2 分，**小于 1 血的 0.98 分**——只在同血时裁决；同血时第一顺位是「出卖次数少者」。

为什么不每轮记「当前血量」？那样是先富后穷的算法：前面攒下的血会在后面每轮重复计分，末轮被人一刀砍掉 3 血，排名却可能不动。记变化量，八轮加起来正好等于终局血量，谁的血多谁的分高，一刀就是一刀。

## 越界与裁定

| 情况 | 裁定 |
|---|---|
| 某一方没交 / 弃权 | 该轮视为出「**合作**」（不设防）：对方出卖他照样 +1，他照样 −3 |
| 两人都弃权 | 两边都算「合作」：都不掉血 |
| 血量跌破 0 | 照记负数，出狱只看是否 ≥10 |
| 连续出同一张 | 允许，没有限制 |
| 第 8 轮同血同出卖次数 | 由加时轮按心术点名一方 |

## 一句话

合作是两个人的事，出卖是一个人的事。八轮之后还愿意先松手的那个人，通常不是算不明白，是算明白了还愿意。
